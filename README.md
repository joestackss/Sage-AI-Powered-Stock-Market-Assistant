# 📈 Sage — AI-Powered Stock Market Assistant

Sage is an intelligent mobile app that provides **AI-driven stock market analysis** using real-time financial data and natural language reasoning.
Built with **React Native**, **Expo**, and **TypeScript**, it integrates **Google Gemini AI** for conversational financial analysis and **Yahoo Finance API** for live data.

---

## ✨ Overview

Sage combines mathematical reasoning and AI to interpret financial data, predict trends, and explain stock movements in conversational language.
Users can ask questions like:

> “What does Tesla’s price change mean today?” or “Analyze Apple’s 6-month performance.”

The system uses **real-time computation of stock deltas, volatility, and performance indicators**, translating quantitative data into human-readable insights.

---

## 🚀 Features

### 🤖 AI-Powered Analysis

* Conversational insights powered by **Google Gemini AI**
* Context-aware analysis using real-time market data
* Explains trends, comparisons, and percentage movements in plain English

### 💹 Market Intelligence

* Live stock data from **Yahoo Finance API**
* Calculations of price change, growth rate, and moving averages
* Portfolio-level performance summaries

### ⭐ User Interaction

* Smart watchlist management with local persistence
* Interactive AI chat assistant
* Real-time stock updates with visual indicators

---

## 🧠 Technology Stack

* **React Native + Expo (TypeScript)** — Cross-platform mobile framework
* **Zustand + React Query** — State and data management
* **Google Gemini AI** — Conversational reasoning model
* **Yahoo Finance API (via RapidAPI)** — Market data integration

---

## 🧮 Mathematical Reasoning Applied

* Percentage change calculations
* Real-time rate-of-return and delta evaluations
* Portfolio total gain/loss computation
* Time-series reasoning for recent performance trends
